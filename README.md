# 🚀 Contexto AI - Smart Wellness Dashboard

Contexto AI is a cutting-edge **Flutter** application that leverages real-time smartphone sensor data (Accelerometer) and processes it using the **Llama 3.3 70B model (via Groq API)** to provide intelligent activity classification and health audits.

## ✨ Key Features

- 🧠 **AI Context Awareness:** Uses Llama 3.3 to analyze $x, y, z$ accelerometer values.
- 🏃 **Real-time Tracking:** Classifies movement into categories like *Walking*, *Stationary*, or *Intense Activity*.
- 📊 **Wellness Audit:** Provides professional feedback based on your movement patterns.
- 🛡️ **Secure Architecture:** Uses `.env` variables to keep API keys safe and private.
- 🎨 **Modern UI:** Built with **GetX** for smooth state management and a clean dashboard.

---

## 🛠️ Tech Stack

- **Framework:** [Flutter](https://flutter.dev/)
- **State Management:** [GetX](https://pub.dev/packages/getx)
- **AI Model:** Llama 3.3 70B (Groq Cloud)
- **Sensors:** Accelerometer (via `sensors_plus`)
- **Backend Communication:** HTTP / Groq API
